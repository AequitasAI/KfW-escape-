# ASSET INTEGRATION PROMPT

Wenn finale Fantasy-Assets in `08_assets/final/` liegen:

1. Asset-Lizenz/Quelle nicht erfinden; nur lokale Dateien nutzen.
2. Szenen als responsive Background-/Layer-Komposition integrieren.
3. Figuren separat layern, wo vorhanden.
4. UI-Lesbarkeit hat Vorrang; nötigenfalls lokale Overlay-/Gradientflächen verwenden.
5. Keine wichtige Information ausschließlich in Bitmap-Art verstecken.
6. Animationen leicht halten: transform/opacity bevorzugen.
7. WebP/AVIF sinnvoll komprimieren; mobile Varianten erzeugen, falls groß.
8. `prefers-reduced-motion` berücksichtigen.
9. Lighthouse-/Performance-Smoke-Test.
10. `HANDOFF_STATUS.md` + Commit.
