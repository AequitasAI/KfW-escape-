# Asset Brief

Noch keine finalen Illustrationen erzeugen, bevor Art Direction + Brand-Guide abgestimmt sind.

## Benötigte optionale Art Assets

1. `scene_archive.webp`
   - Fantasy-Archiv
   - breite Komposition für Desktop/Display
   - genügend ruhige Fläche für UI/Rätsel

2. `scene_connection.webp`
   - mystische Leitungskammer / Datenbrücke
   - Quelle links, Ziel rechts visuell plausibel

3. `scene_testmasters.webp`
   - monumentale Prüfhalle
   - Raum für zwei große Bauplanflächen

4. `scene_operations_mine.webp`
   - Zwergenmine / Maschinenraum
   - fünf Zahnräder im Fokus
   - Betriebszwerg separat besser als eigener Layer

5. `character_operations_dwarf.webp/png`
   - sympathischer, leicht genervter Betriebszwerg
   - keine reale Person
   - mehrere Expressions optional: neutral / skeptisch / Erfolg

6. `scene_black_gate.webp`
   - dunkles monumentales Tor
   - Platz für Codepanel

7. `character_black_guard.webp/png`
   - schwarzer Ritter / Gatekeeper
   - nicht horrorartig
   - keine reale Person

8. `scene_final_bridge.webp`
   - epische Brücke, fünf Siegel
   - keine echte KfW-Architektur erforderlich

## Empfehlung

Figuren und Szenen als getrennte Layer anlegen, damit Codex:
- Parallax
- leichte Bewegungen
- Reaktionswechsel
- responsive Zuschnitte
umsetzen kann.
