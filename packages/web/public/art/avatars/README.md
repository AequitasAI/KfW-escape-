# Sigel der Gefährten (optional)

Ohne Dateien zeichnet die App die dreissig Sigel selbst – als Wachssiegel-Medaillon mit Emblem.
Das ist der Normalfall und sieht auf dem Beamer wie auf dem Handy sauber aus.

Wer gemalte Portraits möchte, legt sie hier ab:

```
avatar_01.webp … avatar_30.webp
```

`.webp`, `.png`, `.jpg` und `.jpeg` werden in dieser Reihenfolge probiert. Die Nummer entspricht
der Reihenfolge in `packages/shared/src/avatars.ts` – `avatar_01` ist „Hammer der Bauhütte“.

Jede Datei wirkt einzeln: fehlt eine, bleibt für dieses Sigel das gezeichnete Emblem stehen.
Empfehlung: quadratisch, 512×512, Motiv mittig, da die Anzeige rund beschneidet.
